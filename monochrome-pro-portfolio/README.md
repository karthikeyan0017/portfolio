# Monochrome Pro Portfolio

A full-stack portfolio website with a monochrome aesthetic.

## Project Structure

- `frontend/` - static website files
- `backend/` - Express API and business logic
- `database/` - collection and schema notes

## Getting Started

1. Install frontend dependencies if needed.
2. Run the backend server from the `backend/` folder.
3. Open the frontend pages in a browser.

## Notes

This project is scaffolded for development and can be expanded with real data, authentication, and deployment configuration.
